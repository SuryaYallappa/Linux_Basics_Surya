# Linux Basics - Surya

## Objective
Practice essential Linux command-line operations using Ubuntu on WSL.

## Tasks Completed

1. Created and renamed files/directories using `mkdir`, `touch`, and `mv`.
2. Viewed file contents using `cat`, `head`, and `tail`.
3. Searched for patterns using `grep`.
4. Compressed and extracted directories using `zip` and `unzip`.
5. Downloaded data using `wget`.
6. Changed file permissions using `chmod`.
7. Created an environment variable using `export`.

## Environment

- OS: Ubuntu on WSL
- Shell: Bash
